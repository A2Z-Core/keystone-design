## 🏛️ Purpose & Usage
* **Engine & Backend Parity**: Ensures game simulation systems, database models, abilities, and quest structures align directly with canonical lore.
* **Client & Engine Parity**: Provides 3D artists, level designers, and narrative writers with detailed reference material for worldbuilding and visual design.
* **Living Document**: This repository evolves as new expansions, zones, classes, and storylines are developed.

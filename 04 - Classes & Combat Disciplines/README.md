# 04 — Classes & Combat Disciplines

This section outlines the playable combat classes, martial arts, spell schools, and specializations available to players.

---

## Key Topics to Establish:
1. **Class Lore & Origin**: Where does this combat discipline come from? How is a champion trained?
2. **Combat Role**: Tank, Melee DPS, Ranged Physical DPS, Spell DPS, Healer, Buffer/Debuffer.
3. **Primary & Secondary Power Resource Systems**:
   * **Rage / Momentum**: Starts at 0, generated through melee combat, spent on heavy strikes.
   * **Energy / Focus**: 100 max pool, fast steady regeneration, combo point generation.
   * **Mana**: Large pool, intellect-driven, drains with spellcasting, recovers out of combat or via spirit.
   * **Faith / Devotion**: Holy charges built and spent on blessings, smites, and divine wards.
4. **Armor & Weapon Proficiencies**: Plate, Mail, Leather, Cloth; Swords, Axes, Staves, Bows, Wands, etc.

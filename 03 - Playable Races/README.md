# 03 — Playable Races

This section covers the playable ancestries, mortal civilizations, and cultures that players can choose when creating a character.

---

## Key Topics to Establish:
1. **Racial Profiles**:
   * Physical characteristics, lifespan, sexual dimorphism, and aesthetic cues.
   * Cultural ethos, religious/spiritual practices, and societal hierarchy.
   * Architectural, armor, and weapon styling.
   * Historical origins and relation to the world Keystones.
2. **Inherent & Racial Traits**: Minor passive affinities, active utilities, or aesthetic distinctions.
3. **Faction Allegiances**: Which factions/nations each race aligns with by default.
